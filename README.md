# AI-video-transcript-and-summary-with-Q-A
An AI-powered video understanding system that converts video into text, generates an automatic summary, and allows users to ask context-aware questions about the uploaded video.

The application is built as a Dockerized FastAPI backend and combines speech recognition, text summarization, vector search, RAG, and an LLM-based conversational agent.

## 🚀 Features

- 🎥 Upload video files through a REST API
- 🎙️ Extract speech from video using Whisper
- 📝 Generate automatic video summaries
- ✂️ Split transcripts into searchable chunks
- 🔢 Generate semantic embeddings using Sentence Transformers
- 🔎 Perform vector similarity search using FAISS
- 💬 Ask questions about the uploaded video
- 🧠 Context-aware answers using RAG
- 🤖 LLM-based responses using Qwen3
- 🔗 Agent orchestration using LangGraph
- 🌐 REST API built with FastAPI
- 🐳 Fully containerized using Docker
- 📚 Interactive API documentation with Swagger
